NotesLab static export (GPL v2+, theme by Automattic)

1. Create a GitHub repo named yourusername.github.io
2. Upload everything in this folder (including the hidden .nojekyll file) to the repo root
3. Settings -> Pages -> Deploy from a branch -> main / root

Edit the text directly in index.html, about/index.html and publications/index.html.
Placeholder text on the homepage (title, "DIER research team", 142 papers, 14 fellows) must be replaced.
